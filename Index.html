Sources

Deux onglets du classeur REPORTING NATIONAL : IMPORT DONNEES (zone SYNTHESE, colonnes AM:AZ) pour la table de faits — un couple pôle × action par ligne — et BDD NOMS pour la dimension pôle (filière, territoire, régions). La jointure se fait sur le code pôle.

Les trois indicateurs

Terminées / concernées : nombre de couples pôle × action à 100 % divisé par le nombre de couples « concernés » (tout sauf « Abandonnée » — un pôle à 0 % reste concerné, il n'a simplement pas encore progressé). Formule vérifiée directement dans les onglets par filière du classeur national (ex. SAN!J10/K10).

Moyenne d'avancement : moyenne des pourcentages d'avancement parmi les couples concernés. Contrairement au premier indicateur, aucune formule vivante équivalente n'a été retrouvée dans le classeur national pour la vérifier (l'onglet qui porte ce nom s'est révélé être une copie mal étiquetée du premier indicateur) — c'est une interprétation raisonnable, pas une valeur confirmée par une référence externe.

Taux de réponse : part des pôles connus (BDD NOMS) ayant au moins un avancement non nul, tous couples pôle × action confondus. Vérifié : correspond exactement aux « % de réponses » déjà affichés dans le classeur national, filière par filière.

« A répondu » compte depuis toujours, pas seulement la campagne en cours — distinguer les deux reste une question ouverte avec le responsable de l'outil.

Filières PA/DOM et PADOM

BDD NOMS regroupe ces pôles sous une seule filière PADOM (Personnes Âgées + soin à DOMicile). IMPORT DONNEES, lui, étiquette chaque ligne PA ou DOM séparément. Le dashboard résout la filière de chaque ligne via le code pôle et BDD NOMS — donc via PADOM — plutôt que via la colonne Filière d'IMPORT DONNEES : les deux libellés se retrouvent donc réconciliés sous un seul indicateur, sans qu'aucune donnée source n'ait besoin d'être modifiée.

Territoires

Un territoire est une lettre ou un numéro (ex. Territoire A, Territoire 3) propre à chaque filière, associé à une liste de régions (ex. HDF - IDF - GE). Les deux nomenclatures (lettrée / numérotée) coexistent selon les filières — c'est normal, chacune est propre à sa filière (cf. CLAUDE.md).

Limites connues

  • PROT ENFANCE n'a aucune ligne dans IMPORT DONNEES (zone SYNTHESE) : ses données sont alimentées autrement dans le classeur national. Affiché comme « donnée non disponible », jamais comme un faux 0 %.
  • OUTRE-MER : le pôle correspondant dans BDD NOMS a un code vide, donc pas d'univers de pôles fiable pour cette filière (taux de réponse non calculable) — à corriger à la source.
  • Les données lues ici reflètent le classeur au moment du dernier chargement de cette page : en cas de doute sur un chiffre, vérifier dans le Sheet vivant avant tout usage en réunion.
